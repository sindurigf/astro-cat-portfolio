# Security

Replace the two contacts below with your own before publishing.

Report a vulnerability privately, not in a public issue:

1. GitHub private vulnerability reporting on this repository: "Report a
   vulnerability" on the Security tab. Turn it on under Settings > Code
   security > Private vulnerability reporting.
2. Email the address in `person.email` in `src/site.config.ts`, currently
   <hello@example.com>.

- `/.well-known/security.txt` publishes the same email address and what the
  site runs. It is generated by `src/pages/.well-known/security.txt.ts`.
- `tests/security-txt.spec.ts` fails when this file stops naming the
  configured address, or when `security.txt`'s `Expires` date nears.
- Accessibility barriers are not security reports:
  [ACCESSIBILITY.md](ACCESSIBILITY.md#8-reporting-a-barrier).
